**Question No 1 - 5 Marks**
Create a Java class `Student` with attributes `name`, `regNo`, and `cgpa`. Provide a constructor to initialize these attributes and a method `displayInfo()` to display the student information. Create two `Student` objects in the `main()` method and display their details. 


**Question No 2 - 5 Marks**
Create a Java class `BankAccount` containing private attributes `accountNumber` and `balance`. Implement appropriate getter/setter methods and methods `deposit()` and `withdraw()`. The `withdraw()` method should prevent withdrawal if the requested amount exceeds the available balance. 


**Question No 3 - 5 Marks**
Create a Java class `AirConditioner` containing attributes isOn and temperature. Implement a method `operate()` that checks whether the air conditioner is switched on. If it is on and the temperature is high, the air conditioner should start cooling; otherwise, it should remain idle. Display an appropriate message for each condition.


**Question No 4 - 5 Marks**
Create Java classes `Student`, `Course`, and `Grade`. A `Student` can register for a maximum of five courses. The `Course` class should store course information, while the `Grade` class should store the marks for each course using a parameterized constructor. Implement appropriate methods to determine the grade and grade points from the marks and calculate the student's Semester GPA (SGPA) for all registered courses.
